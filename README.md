# BestCeiling

Lights and firefoam poppers that go on the ceiling, so they don't take up floor space. There's also a wood-burning chandelier that counts as a brazier for throne rooms.

Fork of Simple Utilities: Ceiling by Owlchemist, updated for 1.7. Don't use both at the same time.
